# コンビニ中綴じ写真集メーカー

写真を渡すと、**用紙を二つ折りしてホチキス留めする中綴じ写真集**の
コンビニ入稿用PDFが出てきます。既定はB4用紙を折ったB5冊子（A4冊子にも切り替えられます）。

`photobook.html` をダブルクリックするだけ。**それだけです。**
Python も pip も要りません。PDF生成ライブラリも中に入っているので
**外部との通信は一切ありません**。写真はブラウザの中だけで処理され、
どこにも送信されません。サーバーに置けばURLで配れます。

---

## 使い方

1. `photobook.html` をダブルクリックしてブラウザで開く
2. 左の枠に写真フォルダをドラッグ＆ドロップ（クリックして選んでも可）
3. 読み込むと**自動で台割が組まれます**
4. 中央のページを**ドラッグして並べ替え**、クリックして選択
5. 右で版面を変える・**写真を縦に回転**する・写真を差し替える・キャプションを打つ
   （複数ページをまとめて消したいときは上部の「**選択**」→ 下記）
6. 上部が「◯ページ ／ A3用紙◯枚」になったら「PDFを作る」
7. `photobook_B5_tate.pdf` を保存する（**これ1本で1冊ぶん**）

**ページ数が4の倍数でないあいだはPDF生成ボタンが押せません。**
「白ページを◯枚足す」を押せば解消します。中綴じの物理的な制約です。

### ページの向き

上部のプルダウンで**縦ページ／横ページ**を選べます。

| | 縦ページ | 横ページ |
|---|---|---|
| ページ（B5冊子） | 182×257mm | 257×182mm |
| とじ | 左とじ（横にめくる） | **上とじ（上にめくる）** |
| 店頭で選ぶ用紙 | A3 | A3 |
| 使う版面 | `templates.json` の `templates` | `templates_landscape` |

向きを変えると**版面の種類が入れ替わる**ので、台割は自動で組み直されます。
一覧のカードも横長表示に変わります。

マルチコピー機のボタンは**どちらも「左とじ / 上とじ」**です。ページが縦か横かを
機械が見て、縦なら左とじ、横なら上とじに自動でなります。書き出し画面にも出ます。

### 自動台割

**写真を読み込むと自動で組まれます。**組み方は既定で「全ページいっぱい」です。
ボタンは置いていません（読み込みと向きの切り替えのときに自動で走ります）。

`config.json` の `plan_mode` で組み方を変えられます。

| `plan_mode` | 中身 |
|---|---|
| `fill`（既定） | 全ページ全面。**ページと向きの違う写真は90°回して合わせます** |
| `portrait` | 全面と標準余白を交互に混ぜる |
| `simple` | 写真の縦横に応じて標準の版面を割り当てる（縦ページのみ） |

回転は「ページに合わせる」向きです。**縦ページでは横写真を、横ページでは縦写真を**回します。
既定は**90°**（時計回り）。`config.json` の `rotate_degrees` で 270 にもできます。
**表紙だけは回しません**（タイトルまで倒れてしまうため。全面写真なので切り抜きで収まります）。

### 写真をページに入れる

左のサムネイルを**中央のページにドラッグ**すると、そのページに入ります。
落とせるページは緑の枠で囲まれます。

- 写真の入っているページ → **差し替え**
- 白ページ・裏表紙など写真を置けない版面 → **「縦・ページいっぱい」に変えて**入れる
- 2枚組の版面 → 空いているほうへ。両方埋まっていれば1枚目を差し替え

縦いっぱいの版面では、入れた写真の向きに合わせて**回転が付け直されます**
（横写真なら90°回転、縦写真なら回転なし）。前の写真のための回転が残って
横倒しになることはありません。

サムネイルを**クリック**すると、裏表紙の手前に新しいページとして足されます。

### 並べ替え

中央のページをドラッグすると順番を変えられます。**掴んでいるページは薄くなり、
入る位置に緑の縦線が出ます。**カードの左半分に重ねればその手前、右半分なら後ろ。
カードのない余白に落とすと末尾へ移ります。

選択モード中はドラッグできません（クリックが選択に使われるため）。

### タイトルをつける

右ペインの「**本の情報**」でタイトル・サブタイトル・クレジットを入れます
（ページを選んでいないときに出ます。ページ選択中は右下の折りたたみから）。
表紙の `{title}` `{subtitle}`、裏表紙の `{credit}` に入り、その場で反映されます。

### 書体を選ぶ

タイトル・サブタイトル・クレジットは、それぞれ**28書体**から選べます。

| 分類 | 書体 |
|---|---|
| 和文・明朝 | ヒラギノ明朝 / 游明朝 / 凸版文久明朝 / 凸版文久見出明朝 |
| 和文・ゴシック | ヒラギノ角ゴ / 游ゴシック / 凸版文久ゴシック / ヒラギノ丸ゴ / 筑紫A丸ゴシック |
| 和文・その他 | Klee（楷書）/ 游教科書体 |
| 欧文・サンセリフ | Helvetica Neue / **Futura** / **Avenir Next Condensed（縦長）** / Avenir Next / Optima / Gill Sans / Impact |
| 欧文・セリフ | Georgia / Didot / Bodoni 72 / Baskerville / Hoefler Text / Copperplate |
| 欧文・その他 | American Typewriter / Rockwell / Menlo（等幅）/ Snell Roundhand（筆記体） |

既定は **タイトル＝ヒラギノ明朝／サブタイトル・クレジット＝Helvetica Neue** です。
サブタイトルとクレジットは日付や名前になりやすいので欧文にしてあります。

**これらはmacOSに入っているフォントを使っています。**外部から読み込まないので
通信は発生しませんが、**Windowsでは入っていない書体が別のものに置き換わります**。
自分のMacで作るぶんには、選んだとおりの書体でPDFになります。

欧文書体を選んでも**日本語は表示されます**（欧文字だけ欧文書体になり、
日本語は明朝／ゴシックへ自動で落ちます）。版面が太字を指定していれば太さは保たれます。

キャプションの書体は版面側で決まります（`templates.json` の `font`）。

### 表紙の文字を組む

タイトルとサブタイトルは**ひと組**として扱われ、次を選べます。

| 項目 | 内容 |
|---|---|
| **位置** | 左上 / 右上 / 左下 / 右下 の四隅 |
| **大きさ** | それぞれptで指定（空にすると版面の既定） |
| **色** | カラーパレット / **カラーコード**（`#ffcc00`）/ **スポイトで写真から吸う** |
| **書体** | 28書体から |
| **帯（座布団）** | 文字の下に敷く。色と濃さを指定 |

位置はページの寸法から計算するので、**冊子サイズや向きを変えても追従**します。

- **下寄せ**のときはサブタイトルが下端に固定され、タイトルの行が増えると**上へ**伸びます
- **上寄せ**のときはタイトルが上端に固定され、行が増えるとサブタイトルが**下へ**ずれます

どちらでも文字が重なりません。

### 帯（座布団）

「文字の下に帯を敷く」をONにすると、**選んだ隅のページ端から帯が伸びて**文字を包みます。
写真の上に文字を載せるとき、明るい空や白い被写体に文字が埋もれるのを防げます。

- 帯の長さは**文字量に追従**します（タイトルが長くなれば伸びます）
- 色はパレット / カラーコード / スポイトで指定。**濃さ**（不透明度）も0〜100%で調整できます
- PDFには**ベクターの矩形**として入るので、拡大してもエッジが滲みません

色はパレット・カラーコード・スポイトのどれからでも決められ、**3つは常に同期します**。
コード欄は `#ffcc00` のほか、`ffcc00`（#なし）や `fc0`（3桁）でも受け付けます。

**スポイト**は画面のどこからでも色を吸えます（写真の上に載せる文字色を、
写真そのものから拾えます）。Chrome / Edge で使えます。
対応していないブラウザではパレットとコード欄を使ってください。
サブタイトルとクレジットは日付や名前になりやすいので欧文にしてあります。

欧文書体を選んでも**日本語は表示されます**（欧文字だけ欧文書体になり、
日本語は明朝／ゴシックへ自動で落ちます）。版面が太字を指定していれば太さは保たれます。

キャプションの書体は版面側で決まります（`templates.json` の `font`）。

この設定は文字の中身とあわせて**ブラウザに保存され、次に開いたときも残ります**
（写真と台割は残りません）。

### 見開きプレビュー

上部の「**プレビュー**」を押すと全画面になり、**実際にめくったときの見開き**で確認できます。

- **表紙（1ページ目）と裏表紙（最終ページ）は単独**で表示されます。相手のページがないためです
- 間は 2|3、4|5 … と組になります
- 下部のボタン、または `←` `→` でめくり、`Esc` で閉じます。真ん中に折り目の影が入ります
- 右開き（`binding: "right"`）にすると左右が入れ替わります

ページを選んでいるときは、右ペインの「この見開きを大きく見る」からそのページの
見開きを直接開けます。

### まとめて選ぶ・まとめて消す

上部の「**選択**」を押すと選択モードになります。

- ページをクリックすると選択され、**Shift＋クリック**で範囲選択できます
- 右側に「すべて選択」「選択を解除」と、選んだページの「複製」「削除」が出ます
- もう一度「完了」を押すと通常モードに戻ります

**写真も同じように消せます。**左側「写真」の見出しにある「選択」を押すと、
サムネイルを複数選んでまとめて削除できます。削除した写真が台割で使われていた場合、
ページ自体は残り、その枠だけが空きます（版面の位置はずれません）。

### 解像度と画質

上部の数字で変えられます。既定は**最高値の300dpi / 品質95**から始まります。
マルチコピー機の推奨がカラー300dpiなので、それ以上に上げても機械側で活かされません。

容量に上限のある入稿経路（ネットプリント等）を選んだときは、ここが**上限値**として
扱われ、収まるところまで自動で下がります。USBメモリ入稿なら下がりません。

### スマホ・タブレット

画面が狭いときは1カラムになり、下のタブで **写真 / 台割 / 編集** を切り替えます。
ページをタップすると自動で「編集」に移ります。

ドラッグ操作はタッチでは動きません（HTML5のドラッグ＆ドロップは
タッチデバイスで `dragstart` が発火しないため）。**代わりにボタンで同じことができます。**

- **並べ替え** … 編集タブの「← 前へ / 後ろへ →」
- **写真を入れる** … 編集タブの「写真」でサムネイルをタップ →
  写真タブに移るので、入れたい写真をタップ

どちらもPCでも使えます。写真を数十枚読み込むとスマホではメモリが厳しくなります。

### 弱点

- 起動のたびに写真を選び直す必要があります（ブラウザはフォルダを覚えられないため）
- 文字は画像として埋め込んでいます。日本語フォントをPDFに埋め込むと7MB級の
  ファイルを読ませることになるため、ブラウザの標準日本語フォントで描画して
  貼る方式にしました。300dpi相当なのでコンビニ出力では問題ありませんが、
  拡大するとベクター文字ほどシャープではありません
- 写真が数百枚になるとブラウザのメモリを圧迫します

## 出てくるもの

**`photobook_B5_tate.pdf` の1本だけ**です（冊子サイズと向きが名前に入ります）。
仕上がりサイズ・全ページ順のPDFで、面付けはされていません。

### 面付けはマルチコピー機がやります

セブン-イレブンのマルチコピー機には「**小冊子プリント**」という機能があり、
ページ順のPDFを渡すと**中綴じの面付けを自動でやってくれます**。
こちらで面付けする必要はありません。

> 小冊子プリントとは、自動で面付けしてくれる便利な機能です。
> — 富士フイルムBIジャパン『小冊子プリント パーフェクトガイド』

### 店頭での操作

1. 「プリント」→「普通紙プリント」→「メディア」（USBメモリを挿す）
2. ファイルを選び「ふつうのプリント」
3. **用紙サイズ → B4**（B5冊子にするため2倍の紙を使います。A4冊子ならA3）
4. **小冊子 → 左とじ**（右開きにしたいなら右とじ）
5. **ちょっと小さめ → する**（端が切れるのを防ぎます）
6. プリント後、真ん中で二つ折りしてホチキス留め

**「両面」や「2枚を1枚」は選ばないでください。** 小冊子プリントが両面と面付けを
まとめて行います。マルチコピー機にホチキス機能はないので、綴じるのは手作業です。

書き出し画面にもこの手順が出ます。

| 仕上がり | 上部で選ぶもの | 店頭で選ぶ用紙 |
|---|---|---|
| **B5冊子（既定）** | B5冊子 | **B4** |
| A4冊子 | A4冊子 | A3 |

### 容量の上限は入稿経路で決まります

既定は **USBメモリ入稿（容量無制限）** なので、画質を落とさずに1本にまとめられます。

| 入稿経路 | ファイル容量の上限 |
|---|---|
| **USBメモリ・SDカード**（マルチコピー機に直挿し・既定） | **無制限** |
| マルチコピーアプリ（Wi-Fi転送） | 30MB |
| ネットプリント / かんたんnetprint | 10MB |

ネットプリントで通したいときは `config.json` の `delivery` を `netprint` にします。
その場合は**収まるまで解像度を自動で下げます**（300dpi から最大120dpiまで。
必要な縮小率を見積もって一気に段を飛ばすので、たいてい2回組むだけで決まります）。
採用された設定は書き出し画面に表示されます。

**ページ数は99ページまで**です（マルチコピー機が一度に扱える上限）。

## 版面（テンプレート）

右ペインの「版面」プルダウンから、ページごとに選べます。

### 標準

| 名前 | レイアウト | 写真 |
|---|---|---|
| `portrait-fill` | ① 縦写真・ページいっぱい | 1 |
| `landscape-wide` | ② 横写真・上下中央・幅いっぱい | 1 |
| `portrait-one` | ③ 縦写真1枚・標準余白 | 1 |
| `landscape-one` | ④ 横写真1枚・標準余白 | 1 |
| `landscape-duo` | ⑤ 横写真2枚・上下 | 2 |
| `rot-fill` | ⑥ 横写真を縦に回転・ページいっぱい | 1 |
| `rot-one` | ⑦ 横写真を縦に回転・標準余白 | 1 |
| `portrait-duo` | ⑧ 縦写真2枚・横並び | 2 |

### 表紙・裏表紙

| 名前 | 中身 | 写真 |
|---|---|---|
| `cover` | 全面写真＋白抜きタイトル | 1 |
| `cover-quiet` | 小さな写真と大きな余白 | 1 |
| `back-cover` | クレジットのみ（写真なし） | 0 |
| `back-cover-fill` | 全面写真＋白抜きクレジット | 1 |
| `back-cover-photo` | 小さな写真＋クレジット | 1 |

ほかに `text`（扉・あとがき）/ `blank`（白ページ）。
表紙の既定は `config.json` の `cover_template`。

### 入れる文字を選ぶ

表紙・裏表紙を選ぶと、右ペインに「**入れる文字**」が出ます。
**タイトル / サブタイトル / クレジット**をそれぞれ入れるか外すか、
チェックボックスで切り替えられます。

版面を何種類も用意する代わりに、この切り替えで組み合わせを作ります。たとえば

- 表紙＝全面写真、タイトルだけ入れてクレジットは外す
- 裏表紙＝全面写真、クレジットも外して写真だけにする

文字の中身は右ペイン下の「本の情報」で決めます。ここで切るのは**そのページだけ**です。

### ［応用］

見開き全面（`spread-L`/`spread-R`）・小口寄せの非対称配置・3点の帯・4点グリッドなど
16種類。自動台割では使われないので、ページを選んでプルダウンから指定します。

- **見開き**は `spread-L` と `spread-R` に同じ写真を指定し、
  必ず **偶数ページ→奇数ページ** の順に隣り合わせます。1枚の写真が左右に割れて
  つながります（A3用紙の中央＝ノドは印字可能なので途切れません）
- `-L` は左ページ（偶数）、`-R` は右ページ（奇数）専用です。逆に置くと崩れます

## 回転

ページを選ぶと右ペインに回転が出ます。**`↺` `↻` を押すたびに90°ずつ回ります**
（0° → 90° → 180° → 270° → 0° とぐるぐる回ります）。「戻す」で0°に戻ります。
台割のカードにも現在の角度が出ます。

**90°と270°のときは版面も自動で入れ替わります。** 紙面に対して写真の縦横が
逆になるためで、`landscape-one` ↔ `portrait-one` のように対応表
（`templates.json` の `rotate_pairs`）にそって差し替えられます。
0°と180°は向きが変わらないので元の版面に戻ります。

自動台割の「全ページ縦（横は回転）」を選ぶと、横位置の写真を90度回して
全ページを縦位置に揃えた台割を作ります。縦位置で撮った写真は回さずそのまま流れます。
このときの回転の向きは `config.json` の `rotate_direction` で決めます。

既定は `90`。`270` にすると逆向きに倒れます。ページごとに右ペインの回転ボタンでも変えられます。

## 見た目を調整する

`config.json` と `templates.json` を直したら、**再アセンブルが必要です**（下記）。

### `config.json` — 冊子全体

| 項目 | 意味 |
|---|---|
| `title` / `subtitle` / `credit` | 表紙・裏表紙に入る文字 |
| `safe_margin_mm` | 用紙端の余白。コンビニ機の非印字領域は約5mm、折りズレの保険で **7mm** |
| `gutter_mm` | ノド（折り目）側の逃げ。写真が谷折りに食われるのを防ぐ |
| `image_dpi` / `jpeg_quality` | 画質。300dpi/95＝最高値（画面には出していません） |
| `delivery` | 入稿経路。`usb`（無制限・既定）/ `app`（30MB）/ `netprint`（10MB）。画面には出していません |
| `book` | 仕上がりの冊子サイズ。`B5`（用紙B4・既定）/ `A4`（用紙A3） |
| `plan_mode` | 自動台割の組み方。`fill`（既定）/ `portrait` / `simple` |
| `orientation` | ページの向き。`portrait`=縦（左とじ）/ `landscape`=横（上とじ） |
| `cover_pos` | 表紙の文字の位置。`tl` / `tr` / `bl`（既定）/ `br` |
| `band` / `band_color` / `band_opacity` | 帯の有無・色・濃さ（%） |
| `binding` | `left`=左開き（店頭で「左とじ」）/ `right`=右開き（「右とじ」）。ノド逃げとノンブルの左右も追従 |
| `font_title` / `font_subtitle` / `font_credit` | 既定の書体。`mincho` / `gothic` / `serif` / `sans` |
| `page_numbers` | ノンブルの有無。表紙・裏表紙・白ページには入りません |
| `cover_template` | `cover` / `cover-quiet` |
| `rotate_degrees` | 自動で回すときの角度。`90`（既定）/ `270` |

### `templates.json` — 版面

座標はすべて **mm・原点はページ左上**（x=右、y=下）。A4は 210×297mm。

```json
"landscape-one": {
  "label":  "④ 横写真1枚・標準余白",
  "slots":  1,
  "page_side": "any",
  "gutter": true,
  "images": [{ "slot": 0, "x": 20, "y": 92, "w": 170, "h": 113, "fit": "contain" }],
  "texts":  [{ "content": "{caption}", "x": 20, "y": 214, "w": 170, "size": 7.5 }]
}
```

- `slots` … このページが消費する写真の枚数（必須）
- `page_side` … `odd`=右ページ専用 / `even`=左ページ専用 / `any`（必須）
- `gutter` … `false` にするとノド逃げのズラしをしない（表紙・全面・見開き用）
- `fit` … `"contain"`=写真全体を収める（余白が出る） / `"cover"`=枠いっぱいに敷き詰めて切る
- `src_crop` … `[x0,y0,x1,y1]` を0〜1で指定。1枚を見開きの左右に割るのに使う
- `anchor` … `"bottom"` にすると、行が増えたときに下ではなく**上へ伸びる**（表紙のタイトル用）
- `font` … 書体のキー（`mincho` / `gothic` / `futura` / `didot` など28種）。末尾に `-bold` を付けると太字。一覧は `app.js` の `FONTS`
- 差し込める文字 … `{title}` `{subtitle}` `{credit}` `{caption}` `{caption2}` `{pageno}`
- 新しい版面は、既存のものをコピーして名前を変えるのが手軽です

`label` の書き出しで右ペインのグループが決まります。
`①`〜`⑧`始まり→標準、`［応用］`始まり→応用、それ以外→表紙・その他。

## 仕組み

```
写真（ブラウザ内）
   ↓  app.js     台割を組み、Canvasで版面どおりに描く
画面プレビュー
   ↓  export.js  各ページをJPEG/PNGに焼いて pdf-lib でページ化
photobook_B5_tate.pdf  ← 仕上がりサイズ・ページ順・これ1本
   ↓  マルチコピー機の「小冊子プリント」
自動で中綴じ面付け＋両面プリント
   ↓  手作業
二つ折り＋ホチキス留め
```

中綴じは1枚の紙が4ページ分になるので、総ページ数は4の倍数である必要があります。
どのページがどの紙に来るか（1枚目の表が8|1、裏が2|7…）は機械が計算します。

版面は `templates.json` に **A4（210×297）基準** で書かれていて、B5冊子のときは
比例縮小して使われます。

---

## 覚えておくこと

- **ページ総数は必ず4の倍数**。中綴じは1枚の紙が4ページ分になるためです
- **面付けはしません。**ページ順のまま渡して、マルチコピー機の「小冊子プリント」に任せます
- 店頭では**仕上がりの2倍の用紙**を選びます（B5冊子ならB4、A4冊子ならA3）
- **用紙の外周5mmは印字できません**（コンビニ機の物理的な制約）。`full-page` でも
  5mmの白フチが残ります。ただし **ノド（折り目）側には制限がない**ので、
  見開き写真は真ん中で途切れずにつながります
- 写真はEXIFの回転情報を見て自動で正立させます。縦横の判定もこれに従います
- RAW（.RW2 など）は無視され、JPEG/PNG/TIFF/WebPだけを拾います
- 両面プリントは1枚が2枚分としてカウントされ、料金も2倍になります
- 一度にプリントできるのは99ページまでです
- ネットプリントは1ファイル10MBまで。USBメモリ入稿なら容量制限はありません
- 小冊子プリントでは、機械側が余白に合わせてデータを少し縮小します。フチなしにはできません
